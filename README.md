## Overview

This project demonstrates how transaction data, portfolio holdings, and market price data can be combined to build an automated portfolio reporting pipeline powered by Large Language Models (LLMs).

By integrating portfolio transactions with real-time market data from Yahoo Finance, the data pipeline generates concise and insightful daily portfolio summaries automatically.

The project showcases how modern data engineering workflows and LLMs can be leveraged to transform raw financial data into human-readable investment insights.

## Features
- Automated ingestion of portfolio transaction data
- Portfolio return and performance calculations
- Market benchmark comparison
- Integration with Yahoo Finance price data
- End-to-end report generation workflow


```
Transaction Data
        │
        ▼
Market Price Retrieval (Yahoo Finance)
        │
        ▼
Portfolio & Holdings Calculation
        │
        ▼
Performance Metrics + Benchmark Returns
        │
        ▼
Automated Daily Portfolio Report
```

### Transaction Data
The portfolio transaction dataset will be able to support a wide range of real-world brokerage activities, including:

| Transaction Type            | Description                             |
| --------------------------- | --------------------------------------- |
| Purchase / Sale             | Buy or sell securities                  |
| Transfer In / Out           | Transfer securities between accounts    |
| Money In / Out              | Cash deposits and withdrawals           |
| FX In / Out                 | Foreign exchange currency movements     |
| Stock Split / Reverse Split | Corporate actions affecting share count |
| Dividends                   | Dividend payouts from securities        |


For demonstration purposes, this example portfolio starts with an initial capital of USD 10,000, with sample transactions consisting of the purchase and sale of Alphabet Inc. and Apple Inc. shares.

### Market Price Retrieval
Historical market prices are retrieved using the yfinance library, dynamically pulling the relevant securities held within the portfolio over the required analysis period. This enables accurate portfolio valuation, performance tracking, and return calculations based on historical market data.

### Portfolio & Holdings Calculation
Portfolio holdings and valuations are calculated across the full analysis period on all trading days from Monday to Friday. For non-trading days or public holidays where market price data is unavailable, the latest available market price is forward-filled to ensure continuous portfolio valuation and performance tracking.

### Performance Metrics + Benchmark Returns
Using the daily holdings dataset, the total portfolio asset value is calculated through an aggregation of all holdings across each trading day. Daily profit and loss (PnL) is then derived while accounting for external cash flows and security transfers, enabling the calculation of accurate daily time-weighted returns (TWR) for portfolio performance measurement.

For benchmarking purposes, this example utilizes the S&P 500 index as the reference benchmark. Historical benchmark price data is retrieved using the yfinance library through the ^GSPC ticker, enabling performance comparison between the portfolio and the broader market.

### Automated Daily Portfolio Report
An automated daily portfolio report is generated by combining portfolio holdings, transaction activity, market prices, benchmark performance, and relevant market news into a consolidated daily summary.
